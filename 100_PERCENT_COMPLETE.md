## 🚀 CARA MENJALANKAN

```bash
cd finance-system

# 1. Generate key
php artisan key:generate

# 2. Setup database
# Edit .env:
# DB_DATABASE=finance_system
# DB_USERNAME=root
# DB_PASSWORD=

# 3. Migrate & seed
php artisan migrate --seed

# 4. Run server
php artisan serve
```

**Akses:** http://localhost:8000

**Login:**
- Admin: `admin` / `admin123`
- User: `user` / `user123`
- Viewer: `viewer` / `viewer123`
